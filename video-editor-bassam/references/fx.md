# وضع المؤثرات — «لما أصقّف يصير شي» · «حطلي نار بإيدي» · «ودّيني البحر» · «حوّلني عضلات»

> المستخدم يصوّر نفسه ويطلب بصوته، وأنت تنفّذ. الكلام هو السيناريو: كل طلب قاله بالفيديو يصير مؤثر بلحظته.
> يشتغل **فوق** الخطوات ٣–٦ (قص + تفريغ + تصحيح + `03_cut_zoom.py`) و**قبل** الخطوة ٧ (المشاهد) — لأنه يعدّل الفيديو نفسه (`cutz.mp4`).
> ⛔ القاعدة ٤ (لا تمسّ صورته): هنا هو اللي طلب — بس **المؤثر اللي طلبه بس**، بنافذته بس. باقي الفيديو يمر كما هو.

## متى
- يقول «سوّ اللي أطلبه بالفيديو»، «حط مؤثرات»، «لما أصقّف…»، «نار/برق بإيدي»، «انقلني»، «حوّلني…».
- أو تسمع بالتفريغ جمل طلب موجّهة للمونتاج («حطلي…»، «هون بدي…») → اسأله: «سمعتك تطلب مؤثرات بالفيديو — أنفّذها؟»
- `<work>/mode.json` ← `{"mode": "fx"}` (أو `"full"` مع مؤثرات — المشاهد تنبني فوقها عادي).

## الخطوات

### ٠) أول مرة: `bash scripts/00_setup.sh --fx` — لاقط اليد (mediapipe) لازم حتى بالماك. النماذج (~٢٤ ميقا) تنزل لحالها أول تشغيل.

### ١) وين طلب؟ ووين صقّف؟
```bash
python3 scripts/26_fx_plan.py <work>
```
يطبع كلامه بتوقيته (الجمل اللي فيها طلب معلّمة ◀) والتصقيفات من الصوت بدرجة ثقة. **الاكتشاف اقتراح**:
- الطلبات تفهمها أنت من الكلام — «لما أصقّف بتطلع نار» = طلب مشروط: النار تبدأ **عند التصقيفة** مو عند الجملة.
- تصقيفة ثقتها أقل من 0.5 → اسمعها (قص ثانية حواليها) قبل ما تعتمدها. وطقطقة الأصابع وضربة الطاولة تنلقط بنفس الطريقة.
- **وين يبدأ المؤثر؟** عند الحركة/التصقيفة مو عند الكلمة: «حطلي نار بإيدي» ثم يفتح إيده بعد ثانية → ابدأ لما تنفتح (شوف الفريمات).
- **لين متى؟** لين يطلب غيره، أو ينزّل إيده، أو تخلص الجملة الجاية — واسأله لو مو واضح.

### ٢) اكتب `<work>/fx.json` — واعرضه عليه بكلام بشري قبل الرندر
```json
{ "events": [
  {"id": "clap",  "type": "flash",    "t": 4.10},
  {"id": "clapS", "type": "shake",    "t": 4.10},
  {"id": "fire",  "type": "fire",     "s": 4.10, "e": 9.80, "side": "any"},
  {"id": "beach", "type": "teleport", "s": 12.4, "e": 18.0, "bg": "assets/beach.jpg", "transition": "flash"},
  {"id": "buff",  "type": "ai",       "s": 21.0, "e": 25.5, "prompt": "make him very muscular, huge biceps and shoulders, same t-shirt"},
  {"id": "buffF", "type": "flash",    "t": 21.0}
]}
```
اعرضه كقائمة: «٠:٠٤ تصقيفة ← وميض وهزّة، والنار تولع بإيدك لين ٠:٠٩ · ٠:١٢ تنتقل للبحر …» — **وخذ موافقته**.
التوقيتات على **التايم-لاين المقصوص** (نفس `caps.json`). ⛔ أي حذف بـ`10_script_edit.py` بعدها يزيحها — سوّ الحذف أول.

### ٣) افحص اللقط، عاين، ثم رندر
```bash
python3 scripts/27_fx_render.py <work> --check                 # اليد انلقطت كم ٪؟ القص شايف الشخص؟ (يخرج 3 لو أي نافذة ضعيفة)
python3 scripts/27_fx_render.py <work> --preview 4.3,6,13,22   # فريمات بـfx_preview/ — شوفها بعينك
python3 scripts/27_fx_render.py <work>                         # يكتب cutz.mp4 بالمؤثرات (الأصل بـcutz_nofx.mp4)
bash scripts/04b_remotion.sh <work> sync                       # ريموشن ياخذ النسخة الجديدة، وكمّل الخطوة ٧ أو ٩ عادي
```
- الرندر ~٣ فريم/ثانية بنوافذ المؤثرات (الباقي سريع) — ١٠ ثواني مؤثرات ≈ دقيقتين. شغّله بالخلفية وقل له.
- تعدّل `fx.json` وتعيد براحتك — كل رندر يبدأ من `cutz_nofx.mp4`. ولو أعدت `03_cut_zoom.py`، ينتبه ويعتمد الجديد أصلاً.
- ⛔ اليد < ٧٠٪ → لا ترندر وتسكت: قصّر النافذة على الجزء اللي إيده مبيّنة فيه، أو غيّر `side`، أو قل له.

## الأنواع

### باليد — تلحق إيده فريم فريم (`s` · `e`)
| النوع | شكله | إعدادات |
|---|---|---|
| `fire` | لهب حقيقي الحركة يطلع من كفّه ويضوّي عليه | `size` (1 = حجم كفّه) |
| `lightning` | برق يطقطق حوالين إيده | `color` (افتراضي أزرق فاتح) |
| `smoke` | دخان يطلع من إيده | |
| `sparkle` | لمعات سحرية | `color` (افتراضي لون التمييز من ثيمه) |
| `energy` | كرة طاقة فوق كفّه | `color` (افتراضي سماوي) |

مشتركة: `side` = `any` (الأوضح، ويكمّل مع نفس الإيد) · `both` (الإيدين) · `screenLeft` · `screenRight` (يسار/يمين **الشاشة**، مو إيده اليمين — الكاميرا الأمامية تعكس) · `point` = `palm` (افتراضي) · `tip` (رأس السبابة — «ارسم بإصبعي»).
المؤثر يولع بربع ثانية ويخفت آخر ثلث ثانية لحاله. لو إيده طلعت من الكادر يمسك مكانها لحظة ثم يخفت، ويرجع لما ترجع.

### لحظية — للتصقيفة وأي «بوم» (`t`)
| النوع | إعدادات |
|---|---|
| `flash` وميض | `dur` 0.35 · `color` · `strength` 0.85 |
| `shake` هزّة كاميرا | `dur` 0.45 · `amp` 28 (بكسل) |
| `punch` زوم خاطف | `dur` 0.4 · `zoom` 1.12 |
| `glitch` خربطة ديجيتال | `dur` 0.3 · `amp` 1 |
⛔ الوميض يخضع للقاعدة ٥٠ و`25_flash_check.py` — لا تكرر وميض أبيض كامل أكثر من مرة كل ثانيتين.

### `teleport` — «ودّيني»، «انقلني»، «خليني بالفضاء»
يقصّه عن خلفيته ويحط مكان جديد: `bg` صورة أو فيديو (نسبي لمجلد الشغل، الفيديو يعيد نفسه) · `transition` = `flash` · `glitch` · `dissolve` · `cut` · `tdur` 0.35.
- **الخلفية**: حسب تفضيلاته بالصور (القواعد ١١ و١٥ و٨٩) — صورة مجانية موثوقة، أو **صورة مولّدة** (`references/generated-images.md`): اطلبها **بنفس زاوية كاميرته وارتفاعها** (غالباً مستوى العين، عمودي 9:16، بلا ناس) عشان يبان واقف فيها فعلاً.
- القص أوضح لما خلفيته الأصلية سادة ومختلفة عن لبسه. شعر منفوش أو إضاءة من ورا = حواف أضعف — عاين.

### `ai` — «حوّلني عضلات»، «غيّر لبسي»، «خليني روبوت»… أي تحويل لجسمه أو شكله
هذا ما ينسوى بالرسم — يحتاج **نموذج ذكاء اصطناعي للفيديو** (خدمة مدفوعة بالثانية).
- `prompt` **بالإنجليزي**، وش يتغيّر بالضبط بس — السكربت يضيف تلقائياً «حافظ على نفس الشخص والوجه والكادر والحركة».
- النافذة **قصيرة** (٣–٦ ثواني) — أغلى وأبطأ كل ما طالت، والنماذج تنحرف عن وجهه مع الطول.
- حط `flash` أو `glitch` عند `s` — التحوّل يصير «سحر» بدل ذوبان.
- لا تحط مؤثر يد أو نقل فوق نافذة `ai` — اللقط ينحسب من الأصل.
```bash
python3 scripts/28_fx_ai.py <work>          # يقص المقطع، ويرسله لو فيه مفتاح — وإلا يطبع وش يسوي بيده
```
- **فيه مفتاح** (`FAL_KEY` أو `keys.json` بمجلد بياناته + `fx.aiModel` بـprofile.json): يرسل وينتظر وينزّل `fx_ai/<id>.mp4`.
  معرّف النموذج ومفاتيح مدخلاته **من صفحة النموذج نفسها** — لا تخمّنها. لو رفضت الخدمة، اقرأ رسالتها.
- **ما فيه**: قل له بجملة: «هالجزء يحتاج نموذج ذكاء اصطناعي للفيديو — ارفع هالمقطع مع هالطلب لأي أداة عندك، ورجّعلي الناتج.» وأعطه الطلب بمربع كود ينسخه.
- **افحص الناتج** قبل الرندر (ورقة لقطات): نفس وجهه؟ قيوده (القاعدة ١١)؟ ما فيه تشوّه بالإيدين؟ لو لا → أعد بطلب أوضح أو قصّر النافذة.
- ⛔ المفتاح سرّ: لا تطبعه، ولا تكتبه بأي ملف داخل مجلد الشغل.

## الصوت
المؤثر البصري بلا صوت يطلع ميّت. من `05_sfx.py`/مكتبته: وشّة عند ولعة النار، `thud` مع الهزّة، `whoosh_up` مع النقل…
نفس حدود `05b_sfx_audit.py` — والتصقيفة نفسها صوتها موجود بصوته، لا تضاعفها.

## الكابشن
جمل الطلب («حطلي نار بإيدي») جزء من المتعة — تبقى بالكابشن افتراضياً. لو قال «شيل كلامي للمونتاج»: `10_script_edit.py drop` **قبل** كتابة `fx.json`.

## نصايح التصوير — قلها له لو سأل أو قبل ما يصوّر
- بعد ما تطلب، **استنّى ثانية** قبل الحركة — المؤثر يلحق يدخل والقص ما يقطع الطلب.
- **إيدك كلها بالكادر** وقريبة شوي من الكاميرا، والكف مفتوح للنار والطاقة.
- **صقّف واضح** بعيد عن كلامك (مو فوق جملة).
- كاميرا ثابتة، إضاءة من قدّام، وخلفية سادة لو ناوي تنتقل لمكان.
- للتحوّل بالذكاء الاصطناعي: حركة هادية وجسمك باين — كل ما كان المقطع أوضح، طلع التحوّل أنظف.
